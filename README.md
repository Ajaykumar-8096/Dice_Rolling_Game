🎲 Dice Rolling Game

A simple and interactive Dice Rolling Game built using **Python Flask**, **HTML**, **CSS**, and **JavaScript**.  
The game simulates a dice roll between the user and the computer and displays the result dynamically.

---

 🚀 Features
- Roll dice with a single click
- Random dice generation for user and computer
- Displays win, loss, or tie result
- Clean and responsive UI
- Real-time updates without page reload

---

 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS, JavaScript
- **Logic:** Random number generation & comparison
